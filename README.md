# 📝 Task List
🔗 **Acesse a aplicação online:** (https://task-list-black-chi.vercel.app/)

Uma aplicação simples e funcional de Lista de Tarefas (To-Do List) desenvolvida com HTML5, CSS3 e JavaScript puro (Vanilla JS).

---

## 🚀 Funcionalidades

- **Adicionar tarefas:** Digite e adicione novas tarefas à lista.
- **Validação:** Alerta o usuário caso tente adicionar uma tarefa em branco.
- **Remover tarefas:** Botão dedicado para deletar tarefas concluídas ou indesejadas.
- **Marcação de conclusão:** Checkboxes personalizadas para marcar tarefas finalizadas.
- **Design responsivo e personalizado:** Interface moderna com layout centralizado e paleta de cores em tons de rosa.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação dos elementos da página.
- **CSS3:** Estilização, layout flexbox, personalização de inputs e fontes externas (*Inter* via Google Fonts).
- **JavaScript (ES6+):** Manipulação de elementos do DOM, criação dinâmica de tags e lógica de eventos.
